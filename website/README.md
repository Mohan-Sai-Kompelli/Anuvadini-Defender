# Anuvadini Attendance + Defender: marketing website

Vite + React + TypeScript. GSAP/ScrollTrigger (scroll choreography), Motion for React (UI motion),
Lenis (smooth scroll), React Three Fiber (one lazy-loaded 3D object in the hero, desktop only).

    npm install
    npm run dev      # http://localhost:3010
    npm run build

Before launch, edit `src/config.ts` (CONTACT_EMAIL, PORTAL_URL) and verify every item flagged
"Placeholder" in the Privacy section. All product visuals use illustrative sample data.
